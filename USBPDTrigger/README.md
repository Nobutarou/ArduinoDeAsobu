# V1.0

CH221K を使ったトリガー。おそらくわざわざ切り替えて使わずに、必要なだけ充電器増やすと思う
ので、抵抗は固定式。5V と 12V がほしい。5V もいちいち CH221K を通すことで、充電器の最大能
力、よくあるのが 5V 3A を出せると思うので、通す。

なお Rohm や Renesas のものもあるにはあるのだが、QFN40 とかのやりにくいものかつ、結局マイ
コンでの制御なので、抵抗ポン付けで電圧取れるようにはなってない。そういうファームウェアを自
力で書けばできるんだろうけど、敷居が高すぎる。ということで、実質的に代替 IC がない状況であ
る。

[データシート](https://akizukidenshi.com/goodsaffix/CH224.pdf)
の 6.4 に参考回路図がある。

フューズを入れるので、一応起こし直した
[回路図](./v1.0/USBPDTrigger1.0/USBPDTrigger1.0_Schematics.pdf)
