# v1.0 とにかく作ってみる。

はじめは入出力コンデンサを固定しておこうかと思ったが、世代によっては、セラコンだと発振する
し、ケミコンだと発振するし、ということで、一つにしておくことが難しそうなので、コンデンサも
自分で差すことにする。

コンデンサはピンソケットに挿して、LDO は IC ソケットで迎えに行けば良いかな。コンデンサまで
IC ソケットで迎えにいくのは、UI がひどいことになるし、間違いの元だと思う。

まあ毎回ブレボで確認するよりは、楽、くらいを目指そう。

と思ったのだが、基板にケミコン 3.3uF とセラコン 1.5uF をVin, Vout に付けておいて、それでも
不足してる場合だけ、用意することにしよう。
